# Планировщик задач (Todo-лист)

Веб-сервер на Go для управления задачами с поддержкой повторений.

## Описание проекта

Планировщик задач позволяет:
- Создавать, редактировать и удалять задачи
- Отмечать задачи выполненными
- Создавать повторяющиеся задачи с правилами: ежедневно, еженедельно, ежемесячно, ежегодно
- Искать задачи по тексту или дате

## Выполненные задания со звёздочкой

- [x] Переменная окружения `TODO_DBFILE` – настройка пути к БД
- [x] Поддержка правил повторения `w` (еженедельно) и `m` (ежемесячно)
- [x] Поиск задач по тексту и дате (`?search=`)
